# Six interactive paper explainers

Extend native field notes with paper metadata and six variants of a shared,
accessible experiment surface. Preserve original homepage SVG controller and all
existing articles. Every article distinguishes paper results from original toy
examples and links primary paper + official implementation resources. No hosted
media generation, model API calls, uploads, pushes or deployments.

1. Attention Residuals: normalized learned mixing over eight synthetic layer
   vectors; select query and temperature; compare uniform mixing.
2. Engram: hashed toy n-gram lookup, inspect collisions and contextual gate.
3. Byteification: inspect actual UTF-8 bytes vs a disclosed illustrative chunker;
   conversion stages are explained, not simulated as trained-model performance.
4. Paper2Agent: local reproducibility workflow with selectable dependency/schema/
   reference-test failures and explicit repair steps; no real agents executed.
5. AlphaGenome: hypothetical reference/alternate regulatory tracks with a context
   window and tissue selector; not real DNA/variant effect predictions.
6. DINOv3: normalized synthetic patch features, Gram similarity, drift and an
   illustrative anchor interpolation; not DINO inference or training.

Write ~600 words each covering problem, mechanism, evidence, limitations,
experiment and practical evaluation. Add six locally generated SVG/PNG covers.
Use unique DWG numbers and discovery metadata; constrain related reading length.
Tests cover numerical invariants and workflow gates; build and browser-check all
six routes, interactions, scroll progression, narrow overflow and console logs.
